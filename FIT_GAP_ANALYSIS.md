## Оставшиеся ограничения

1. Название In.Plan и ссылка на исходный inplan-dashboard сохранены намеренно: задача — восстановление недостающих файлов, а не переименование продукта.
2. CODE_AUDIT.md описывает более ранний срез исходного проекта; его выводы не следует считать новым аудитом kama.
3. В server.js задан адрес PostgreSQL исходного окружения. Для рабочего запуска требуется подтвердить сетевой доступ и настройки источников.
4. GitHub Pages обслуживает статические файлы, но не запускает server.js; PostgreSQL-функции требуют отдельного Node-сервера.
5. Перед внешним размещением нужен отдельный разбор существующей модели доступа: CORS с *, параметры подключения от клиента, пароль в localStorage с TTL, режим auto SSL с отключённой проверкой сертификата и возможным переходом без TLS, раздача корня проекта через express.static. Эти настройки не изменялись при восстановлении.
6. Локальная библиотека Excel восстановлена, однако шрифт по-прежнему подключён с Google Fonts; наличие локального XLSX не означает отсутствие всех внешних запросов.

Итог: пробел комплектности относительно предоставленного архива закрывается добавлением 25 файлов. Дальнейшая пригодность для конкретного контура КАМА требует проверки на его данных и согласования требований.
